    HOW IT WORKS
    요약보다 중요한 건,
    확인할 것을 남기는 일.
    01
    근거를 함께 보여줍니다.
    추출한 정보 옆에 원문 구절을 표시합니다. 원문에 없는 인원이나 예산을 임의로 채우지 않습니다.
    02
    애매한 조건은 질문으로.
    ‘다음 달’, ‘협의 중’ 같은 표현과 서로 다른 인원은 확정하지 않고 담당자의 확인 항목으로 남깁니다.
    03
    검토 뒤에 행동합니다.
    결과는 담당자 검토용 초안입니다. 견적 확정, 교육 예약, Slack 발송을 자동으로 수행하지 않습니다.
    

    구현 구조와 실행 방식 보기 +
    브라우저 체험은 실제 입력을 규칙 기반으로 처리합니다. AI 생성 결과나 n8n 실행 결과로 표시하지 않습니다. n8n 연결 환경에서는 같은 입력이 웹훅을 거쳐 처리되고, 요청 ID와 소요 시간을 확인할 수 있습니다.
    문의 입력→입력 검사→정보·근거 추출→검토용 초안
    n8n에서 실제 모델 호출은 이 버전에 포함하지 않았습니다. 공개 샘플을 재현한 구현이며 과거 회사의 원본 워크플로가 아닙니다.
