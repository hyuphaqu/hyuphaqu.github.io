# 오정협 개인 포트폴리오

https://hyuphaqu.github.io/

GitHub Pages에서 제공하는 buildless HTML/CSS/JavaScript 개인 사이트입니다.

## 수정할 곳

- `index.html`: 소개, 대표 프로젝트, 경력, 교육·멘토링, 연락처
- `projects/*.html`: 프로젝트 상세
- `resume/index.html`: 공개 이력서와 복사 기능
- `downloads/`: 공개 이력서 원고
- `assets/style.css`: 반응형 디자인
- `assets/app.js`: 모바일 메뉴와 클립보드 복사

루트에서 정적 서버를 실행하면 미리 볼 수 있습니다. 기본 브랜치 `main`의 루트를 GitHub Pages로 제공합니다. 빌드나 패키지 설치가 필요 없습니다.

## 콘텐츠 기준

- 특정 회사 지원 문구와 검증되지 않은 전환율은 제외했습니다.
- 교육생 서비스는 멘토링 기여 범위를 명시했습니다.
- 아이보틀 공개 서비스에는 고객의 후속 수정이 포함됩니다.
- Python Day6 직접 제작과 Day28 구성 개선의 범위를 구분했습니다.
- GPT 가이드는 ChatGPT·Codex와의 협업 프로젝트로 표시했습니다.
- 프로필은 사용자가 선택했던 AI 생성 이미지입니다.
- 공개 사이트에는 이메일만 기재했습니다. 전화번호를 포함한 제출용 Word 문서는 별도로 관리합니다.

이 사이트의 문구와 구현은 ChatGPT·Codex와 협업해 정리했습니다. 사이트의 제작일은 2026-10-21입니다.
