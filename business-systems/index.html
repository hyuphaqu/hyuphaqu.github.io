01 / VIBE BUILDERS

고객의 설명을
기능과 데이터로.

필요 기능 정리 · 화면 검수 · 테이블 설계 · DB·API 연동

서로 다른 업무를 가진 의사·변호사·사업자 고객의 서비스 제작을 지원했습니다.

파악한 요구
고객이 Claude로 직접 만든 화면을 실제 업무에 쓰려면 필요한 기능과 데이터를 연결해야 했습니다. 환자 검사결과·상담 관리, 1인 법률 상담 등 고객별로 만들려는 서비스가 달랐습니다.
구체화와 구현
고객이 원하는 기능을 함께 정리하고 화면을 검수·수정했습니다. ERDCloud로 테이블을 설계하고 Supabase DB·API를 연결했습니다. 기획이 달라지면 DB 구조도 수정하고, 배포 후 작동하지 않는 기능을 직접 고쳤습니다.
확인한 결과
제작을 지원한 검사결과·상담 관리 서비스를 의사 고객이 실제 사용하는 것을 확인했습니다.
고객의 요구→화면·기능→DB·API→배포·사용

고객 참여형 제작 방식입니다. 고객이 만든 화면을 바탕으로 검수·수정과 데이터 연결을 맡았으며, 사례에 따라 기획·개발·배포까지 지원했습니다.

02 / LEARNING PLATFORM

흩어진 운영 정보를
플랫폼 안으로.

운영 불편 발견 · 개선 제안 · 대시보드·인증 구현 · 직접 운영

직접 쓰던 교육 플랫폼의 관리 방식과 이용자 확인 절차를 개선했습니다.

기존 업무
수강생 정보는 개별 시트에 흩어져 있었고, 별도 로그인 없이 이메일을 대조해 이용자를 확인했습니다.
판단과 변경
플랫폼을 사용하며 발견한 불편과 수강생 피드백을 동료들과 논의하고 개선을 주도했습니다. Supabase를 연결해 수강생 정보·챌린지 참여·수강 상태를 대시보드에서 관리하도록 구성했습니다. 인증 기능을 더하고 로그인·홈 화면과 DB 구조를 수정했습니다.
운영 결과
구현한 대시보드와 인증 기능을 실제 교육 플랫폼 운영에 직접 사용했습니다.

03 / BILLDERS & WORKFLOWS

업무 목적에 맞춰
입력과 처리 흐름을 연결.

사업·고객 접점 기획 · n8n 배포 · 웹훅 연동 · 판매·운영

AI 교육사업 Billders를 기획·판매·운영하며, 고객이 사업아이템을 탐색하는 서비스를 만들었습니다.

필요한 경험
AI로 사업을 시작하고 싶지만 무엇을 만들지 고민하는 고객에게, 관심 분야와 가용 자금 등 자신의 상황을 넣어 아이디어를 탐색할 수 있는 접점이 필요하다고 판단했습니다.
구현한 흐름
체험형 랜딩을 제안·제작하고 Railway에 n8n을 배포했습니다. 웹훅으로 랜딩 요청을 받아 AI 탐색 기능과 연결하도록 백엔드 흐름을 구성했습니다.
확인한 결과
이메일 등록과 상담 신청이 발생했고, 유료 수강으로 이어진 사례를 확인했습니다. 사업과 고객 접점의 기획·구현을 맡았고 교육 콘텐츠는 동료와 함께 구성했습니다.
