직접 만든 Day6 교안 예제 보기 +

「쇼핑몰 상품 분석」 실습 발췌. 상품 데이터는 학습용 예시이며 개인 사업 성과가 아닙니다.

# (상품명, 가격, 리뷰평점, 누적판매량)
products = (
    ('무선 이어폰',      150000, 4.8, 1200),
    ('스마트 워치',      250000, 4.5,  800),
    ('보조 배터리',       30000, 4.9, 3500),
    ('블루투스 스피커',    80000, 4.2,  500)
)

# Q1. 가장 많이 팔린 상품은?
best_seller = max(products, key=lambda x: x[3])
print(f"베스트셀러: {best_seller[0]} (판매량: {best_seller[3]:,}개)")
# 출력: 베스트셀러: 보조 배터리 (판매량: 3,500개)

# Q2. 가장 저렴한 상품은?
cheapest = min(products, key=lambda x: x[1])
print(f"최저가 상품: {cheapest[0]} (가격: {cheapest[1]:,}원)")
# 출력: 최저가 상품: 보조 배터리 (가격: 30,000원)

# Q3. 리뷰 평점이 가장 높은 상품은?
best_rated = max(products, key=lambda x: x[2])
print(f"최고 평점: {best_rated[0]} (평점: {best_rated[2]})")
# 출력: 최고 평점: 보조 배터리 (평점: 4.9)
