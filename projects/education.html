02 / LEARNER FEEDBACK

학습자의 막힘을 보고
설명의 순서를 바꿨습니다.

API 수업에서는 생소한 기술 용어 때문에 후속 설명을 따라가기 어려워하는 상황을 확인했습니다. 실습 전 알아야 할 개념이 먼저라고 판단해, 오늘 배울 기초 용어를 교안 앞부분에 배치했습니다.

관찰한 문제

설명에 앞서 등장하는 낯선 용어

수업에 필요한 기초 용어가 생소해 후속 설명을 따라가기 어려웠습니다.

바꾼 순서

기초 개념을 먼저, 그다음 실습

기초 용어 → 요청·응답 → 데이터 처리 → 확인·응용 순서로 구성했습니다.

이후 학습자가 후속 설명을 따라오는 흐름과 수업 진행이 매끄러워졌다고 관찰했습니다. 이는 강사로서 확인한 정성적인 반응입니다.
