시트에 흩어진 운영을 플랫폼 안으로

플랫폼을 직접 사용하고 수강생의 피드백을 받으며 개선점을 찾았습니다. 개별 시트에서 관리하던 수강 정보를 대시보드로 옮기고, 이메일 대조 방식에 인증 기능을 도입했습니다.

기존 교육 플랫폼의 프론트엔드와 데이터 연결을 수정·확장하고, 직접 운영했습니다.

문제

수강 정보와 서비스 이용이 따로 움직였습니다.

바이브코딩 챌린지를 운영하는 플랫폼에서 수강생 정보는 개별 시트로 관리했습니다. 별도 로그인 없이 이메일을 대조해 이용자를 확인하고 있었습니다.

판단

직접 쓰며 발견한 불편을 개선 과제로 삼았습니다.

플랫폼을 직접 사용하고 수강생의 피드백을 받으며 필요한 기능을 찾았습니다. 동료들과 논의한 뒤, 수강 정보 관리와 이용자 인증을 서비스 안에서 처리하도록 개선을 제안했습니다.

실행

대시보드와 인증 기능을 구현했습니다.

Supabase를 연결해 수강생 정보, 챌린지 참여 여부, 수강 상태를 대시보드에서 관리하도록 구성했습니다. 인증 기능을 도입하고 로그인·홈 화면과 DB 구조를 수정했습니다.

BEFORE

수강 정보를 개별 시트로 관리하고 이메일을 대조해 이용자 확인

AFTER

플랫폼 내부 대시보드에서 정보를 관리하고 인증 기능으로 이용 흐름 연결

결과

만든 기능을 직접 운영에 사용했습니다.

제안한 기능을 개발한 뒤 실제 교육 플랫폼 운영에 사용했습니다. 직접 사용하는 입장에서 문제를 발견하고, 화면과 데이터 구조를 수정하는 경험을 쌓았습니다.

OUTCOME

구현한 대시보드와 인증 기능을 교육 플랫폼 운영에 직접 사용했습니다.
