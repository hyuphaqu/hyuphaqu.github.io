고객이 직접 화면을 만들고, 저는 검수·수정과 데이터 연결을 맡았습니다. 사례에 따라 기획·개발·배포까지 지원했습니다.

문제

화면을 만든 다음에는, 업무가 동작해야 했습니다.

고객에게 Claude를 활용한 제작 방법을 안내하고, 고객이 자신의 서비스를 직접 만들도록 지원했습니다. 실제 사용을 위해서는 화면에 필요한 기능과 데이터를 연결하고, 의도와 다르게 동작하는 부분을 수정해야 했습니다.

판단

고객의 업무를 기능과 데이터로 구체화했습니다.

고객이 원하는 서비스와 필요한 기능을 함께 정리했습니다. 환자 검사결과·상담 관리, 1인 법률 상담 등 서로 다른 업무에 맞춰 화면과 데이터 구조를 구성했습니다.

실행

기능 변경부터 배포 오류까지 직접 수정했습니다.

ERDCloud로 테이블을 설계하고 Supabase DB를 구축했습니다. DB 구조에 맞춰 API를 연동하고, 기획과 기능이 달라지면 데이터 구조도 수정했습니다.

고객이 만든 화면을 검토하며 구현 방법을 안내했습니다. 배포 후 작동하지 않는 기능이나 DB 연결 문제도 직접 수정했습니다.

결과

고객의 실제 업무에 사용하는 서비스가 됐습니다.

제가 제작을 지원한 검사결과·상담 관리 서비스를 의사 고객이 실제 업무에 사용하는 것을 확인했습니다. 고객의 요구를 이해하고, 직접 제작한 결과물을 검수한 뒤 데이터와 배포까지 연결한 경험입니다.

OUTCOME

의사 고객이 환자 검사결과·상담 관리 서비스를 실제로 사용하는 것을 확인했습니다.
