01 / VIBE BUILDERS

고객이 만든 화면을
실제 쓰는 서비스로.

고객 요구 정리 · 제작 검수 · 데이터 연동 · 배포·활용 지원

의사·변호사·사업자 고객이 AI로 만든 화면을 실제 업무에 활용하도록 지원했습니다.

고객의 상황
고객이 Claude로 직접 화면을 만들었지만, 실제 사용을 위해 기능과 데이터를 연결하고 오류를 해결해야 했습니다.
제가 한 일
필요한 기능을 함께 정리하고 화면을 검수·수정했습니다. ERDCloud로 테이블을 설계하고 Supabase DB·API를 연결했으며, 기능 변경에 따른 DB 수정과 배포 후 오류 해결을 맡았습니다.
확인한 결과
제작을 지원한 환자 검사결과·상담 관리 서비스를 의사 고객이 실제 업무에 사용하는 것을 확인했습니다.
요구 정리→화면 검수→DB·API 연결→배포·사용 지원

고객 참여형 제작 방식. 고객이 직접 만든 화면을 바탕으로 검수·수정과 구현을 지원했습니다.

02 / BILLDERS

관심에서 상담으로 이어지는
고객 경험을 만들었습니다.

사업 기획·판매·운영 · 고객 접점 제작 · 유입 확인

AI로 사업을 시작하고 싶지만 무엇을 만들지 고민하는 고객에게, 직접 아이디어를 탐색하는 경험을 제안했습니다.

고객의 상황
정보를 읽는 랜딩에서 이메일 등록 참여가 낮았습니다. 고객이 자신의 관심과 상황을 입력하고 사업아이템을 탐색할 수 있는 접점을 만들고자 했습니다.
제가 한 일
관심 분야·가용 자금 등을 선택하는 체험형 랜딩을 기획·제작했습니다. Railway에 n8n을 배포하고 웹훅으로 AI 탐색 기능을 연결했습니다. 콘텐츠 홍보와 UTM 유입 구분, 안내 메일과 후속 상담도 운영했습니다.
확인한 결과
이메일 등록과 상담 신청이 발생했고, 유료 수강으로 이어진 사례를 확인했습니다. 교육 콘텐츠는 동료와 함께 구성했습니다.

교육팀에서 문의 알림과 문서 작업에 필요한 자동화 흐름을 구현했습니다.

실제 업무 경험

04 / GUIDES & ENABLEMENT

상대가 이해하고
다음 작업을 할 수 있도록.

교육 담당자 소통 · 교안 제작 · 구현 멘토링

비개발자에게 기술을 설명하고, 실제 화면과 오류를 보며 다음 작업을 안내해 왔습니다.

  • 목표와 수준 조율오즈코딩스쿨 담당자와 목표·일정·커리큘럼을 논의했습니다. 팀장 면담과 멘토링으로 파악한 수준에 맞춰 설명과 난이도를 조정했습니다.
  • 구현 중 막힘 해결사업개발캠프에서는 대상 사용자와 해결 문제, 팀 수준에 맞는 구현 범위를 검토했습니다. AI 리더캠프에서는 화면 피드백과 오류 원인·해결 방법을 안내했습니다.
  • 따라 할 수 있는 자료Python·데이터 분석 교안과 예제 코드를 제작했습니다. API 실습은 API·HTTP·요청·응답의 기초 개념부터 설명하도록 구성했습니다.
